导出 → 接入量力

学苗只负责「真实发生了学习」这件事，量力负责把它变成成长点、内心花园和连击。 导出标准 JSON，再在量力里「导入学习记录」即可合并（不覆盖你原有数据）。

在量力里这样接

  1. 学苗点「复制 JSON 文本」或「下载 JSON 文件」。
  2. 打开量力 →「我的」→「数据备份」→ 点「导入学习记录」。
  3. 粘贴文本 / 选文件 → 学习事件会折算成 成长点🌱，并在看板生成「学习连续 / 本周时长」。
  4. 成长点可去「成长池」页的圣物商店换宽恕令牌等。

背哪些词是你自己认领的事——学苗只做「词表引擎」。以下是已实测的开源词表，点 ⬇ 一键导入 即自动联网拉取、解析并建好卡组（下面三本都带中文释义，不用再联网补词义，秒建）：

📄 六级-乱序.txt ≈5,650 词
📄 托福-乱序.txt ≈13,500 词（会慢几秒）
同仓库还有 考研 / 高中 / 初中 / SAT（根目录，同样格式可一键）
② JavaProgrammerLB/cet-word-list 按教育部《四六级考试大纲 2016 修订版》整理 · MIT
📄 word-list.txt（纯词每行一个、无释义，四级+六级合一）——纯词走「联网补释义」很慢，不适合一键；用它的话走上方卡组「批量」粘贴/导入文件，一次 ≤500 词。
③ 提醒：雅思/托福官方从不发布词表，市面全为机构整理版（上面的托福即此类）；四级/六级才有官方大纲词表。雅思在 ① 仓库的 full_line_tsv → 雅思.txt（多列富格式，需先取词头，暂不支持一键）。一键拉不动（大陆网络/断网）时：点文件名手动打开 → 复制全文 → 卡组「批量」粘贴导入，或给直链加 https://ghproxy.com/ 前缀。
  1. 一键：点上方 ⬇ 一键导入 → 自动拉取解析、新建卡组（四级约 3~8 秒，受网络影响）。
  2. 兜底：一键失败就点文件名 → 浏览器打开 .txt → 全选复制 → 任意卡组「批量」粘贴 → 「批量加入卡组」；或「📂 导入文件」选本地 .txt。
  3. 开背：导完自动进 SRS 记忆曲线，直接开背。重复点一键会去重追加，不会建重复卡组。
