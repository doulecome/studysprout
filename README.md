# 学苗 StudySprout

轻量学习监督 · 单文件 H5

只负责「真实发生了学习」这件事;养成聚合交给量力(导出标准 JSON 导入即可)。

借鉴 Forest(专注种树)、Duolingo(每日目标+连击)、Focus To-Do(科目+番茄合一)、不背单词(间隔重复 + 纯词自动补释义)的机制,全部轻量化、零依赖、单文件。

## 怎么跑

直接打开 `index.html`。数据存 localStorage。

## 功能

- **学习**:科目 chips + 番茄专注(计时种树)+ 一键打卡(分钟/次数/产出),今日目标环 + 连续学习天数
- **记录**:今日时长 / 连续 / 本周 / 各科目累计
- **复习**(SRS):间隔重复记忆曲线(level 0→6,间隔 0/1/2/4/7/15/30 天),🧠 回想 / 🔘 选择双模式,多卡组自建
- **批量导入**:`词|释义|例句` 或纯词自动富化(内置词库 → 有道词典联网补义三层管线);考试词表(四级/六级/托福)一键直链导入
- **接量力**:导出标准 JSON → 量力「导入学习记录」→ 折算成长点 / 学习连续 / 本周时长

## 数据 schema(对接量力的接口契约)

```json
[{ "ts": 1690000000000, "subject": "英语", "type": "minutes", "amount": 30, "note": "", "source": "studyapp" }]
```
